# Contributing to CLAN

Thank you for your interest in contributing to CLAN!

## Original Author & Canonical Maintainer

CLAN was created by **Sai Eeshwar** (https://github.com/saieeshward) and **Shreyansh Soni** (https://github.com/batunii).
Sai Eeshwar and Shreyansh Soni are the original authors of the CLAN specification and the
canonical maintainers of this repository, including the official SDK,
CLI, and Viewer.

## How to Contribute

Contributions of all kinds are welcome:
- Bug fixes and improvements to the SDK, CLI, or Viewer
- Documentation improvements
- New examples and use cases
- Feedback on the CLAN specification

Please open an issue before submitting large changes, so we can
discuss the approach.

## Licensing of Contributions

By submitting a pull request, you agree that:

1. Your code contributions are made under the **Mozilla Public License 2.0**

2. Any suggestions or changes to the CLAN **specification** are considered
   input to the spec, which remains the intellectual property of Sai Eeshwar and Shreyansh Soni
   and is licensed under CC BY 4.0.
3. You will not claim authorship of the CLAN specification or represent
   any fork as the original or official CLAN project.

## Attribution

All significant contributors will be acknowledged in the repository.
However, authorship of the original CLAN specification and its canonical
implementation belongs to Sai Eeshwar and Shreyansh Soni.

## Spec Changes

The CLAN specification is authored and curated by Sai Eeshwar and Shreyansh Soni. Community
input on the spec is highly encouraged via issues and discussions, but
final decisions on the spec rest with the original author.

## Code of Conduct

Be respectful, constructive, and collaborative. This is an open project
and everyone is welcome.
